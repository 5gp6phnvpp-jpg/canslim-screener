🔑 Alpha Vantage APIキー取得・設定方法
▶ 取得サイト:
https://www.alphavantage.co/support/#api-key
▶ 取得手順:
  1. サイトにアクセス → 上記リンクをクリック
  2. 質問に回答 → 「Which of the following best describes you?」で「Investor」を選択
  3. 組織名 → 空欄でもOK（または「Personal」と入力）
  4. メールアドレス入力 → 正規のメールアドレスを入力
  5. 「GET FREE API KEY」をクリック
  6. メール確認 → Alpha Vantageからメールが届きます
  7. APIキーをコピー → メール内のAPIキー（英数字の文字列）をコピー
  8. 上のテキストボックスに貼り付け
